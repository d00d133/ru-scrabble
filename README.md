# scrabble-ru

Русский словарь для скрэббла (Эрудит, Балда): `scrabble_ru.txt`.

- UTF-8, одно слово на строку, только строчные буквы а–я и ё.
- Около 2,5 млн словоформ, 58 МБ.
- Словарь широкий: в нём есть редкие формы, междометия и сокращения. Присутствие слова в файле не гарантирует, что оно допустимо по официальным правилам.

Примеры:

```bash
grep -xc 'слово' scrabble_ru.txt          # есть ли слово
grep -E '^к.т.$' scrabble_ru.txt           # поиск по маске
```
